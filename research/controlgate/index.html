Research / Compliance as code

ControlGate

Checks code changes against NIST 800-53 at pre-commit and PR time, with block or warn verdicts and remediation guidance.

Version 0.2.1Released 2026-11-05Python
DOI ↗GitHub ↗Site ↗

The problem

NIST 800-53 and FedRAMP compliance is usually checked at audit time, long after the code that breaks a control has shipped.

What's new

Checks each change at pre-commit and pull-request time across 8 security domains, maps findings to control IDs, and returns block or warn verdicts with remediation. Validated against a suite of deliberately vulnerable projects.

My role

Sole author: designed, built and maintain it.
